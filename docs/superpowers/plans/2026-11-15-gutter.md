# Gutter: line-number strip on the right edge

**Plan:** agreed in conversation on 2026-11-15; authority is the filed spec
(`docs/superpowers/specs/2026-11-15-gutter-design.md`) plus the AGENTS.md
conventions.
**Goal:** add a host-configurable line-number gutter to `PyRaya`: one number per
document line on the right edge, rendered in Eastern or Western digits, coloured
by the theme stop, off by default. It reserves a right strip with
`setViewportMargins`, paints the numbers on a small `GutterArea` child widget
(sibling of the viewport), and recomputes its pixel width dynamically in both
directions as the largest visible line number crosses powers of ten.
**Verification:** the repo's own gate — `uv run pytest`, `uv run ruff check`,
`uv run ruff format`, `uv run pyrefly check` (the latency harness is opt-in and
not run here: `PYRAYA_LATENCY=1 uv run pytest -s` only when a row is in
question).

## Context

- Branch `gutter` is cut from a clean `main`. The spec is committed; the
  working tree is clean.
- The canonical Qt line-number-area pattern (StackOverflow 7961659) is adapted
  to PySide6 and this widget: `setViewportMargins` + child paint widget +
  `updateRequest` handler.
- **Probe facts (load-bearing, verified on PySide6 6.12, offscreen, 2026-11-15):**
  - `updateRequest` delivers `(QRect, int)` to Python: the rect arrives as an
    integer `QRect`, `dy` as `int`. `dy ≠ 0` is reachable under incremental
    scrolling (saw `-60`, `-56`); `dy == 0` is the repaint path.
  - `cursorForPosition` takes a **single `QPoint`** (not two ints);
    `findBlock` on its position returns the block at the viewport's bottom —
    the largest visible line number.
  - `setViewportMargins`: a real change fires the widget's `resizeEvent`
    **synchronously** (not scheduled) and also fires `updateRequest`; a no-op
    change fires **neither**. A margin change **reflows the text** (block
    height 480→564), which is why an active overlay must be re-placed on a real
    width change — and why the existing `PyRaya.resizeEvent → _onViewChanged()`
    path already does it: no separate re-placement hook is needed.
  - Paint coordinate math: `top = int(blockBoundingGeometry(block).translated(
    contentOffset()).top())` is the correct gutter-local y for a block's top
    edge.
  - `GutterArea` as a sibling of the viewport (child of `PyRaya`,
    `setGeometry` at `contentsRect().right() - width, contentsRect().top()`,
    `raise_()`): after `setViewportMargins` + resize it does not overlap the
    viewport and is visible.
  - **Synchronous margin change:** because `setViewportMargins` fires
    `resizeEvent` synchronously, the width recompute in `resizeEvent` recurses
    once per digit-count change and terminates on the no-op guard (the reflow
    can move the largest visible line number across a power-of-ten boundary;
    that one-cycle oscillation is accepted).
- `regions.py` already maps ASCII `0–9` to Eastern Arabic-Indic `۰–۹`
  (`RegionSubstitutions` / `substituteText`); the gutter reuses it.
- `theme.py` holds every colour PyRaya paints (`ThemeTokens` per stop,
  `LightStop` / `DarkStop`, `resolveTheme`). This feature adds three tokens.
- The demo (`src/pyraya/__init__.py:107`) already wires a `Ctrl+D` theme toggle
  via `QShortcut` / `QKeySequence`; the gutter toggle joins it as `Ctrl+L`.
- `PyRaya.resizeEvent` (`pyraya_widget.py:3120`) already calls
  `_onViewChanged()` (`:2207`), which re-places the active overlay. The
  gutter's margin change fires the widget `resizeEvent` synchronously, so the
  existing path handles overlay re-placement: no separate hook needed.
- `PyRaya.__init__` (`pyraya_widget.py:762`) initialises all state fields
  before the highlighter is constructed. The gutter state fields go in the
  same block.
- `PyRaya._applyTheme` (`pyraya_widget.py:914`) re-resolves the widget's
  colours from its palette. The gutter resolves colours per paint from
  `resolveTheme(self.palette())` — the same no-paint-hook pattern as the
  overlay — so no `_applyTheme` hook is needed.
- `PyRaya._applyFont` (`pyraya_widget.py:3532`) applies the document font. The
  gutter font is a **separate variable** on `PyRaya`, independent of the
  document font: `setGutterFont` sets it and triggers the width recompute;
  document font changes never repoint it.

```python
# ******************************************************************************
# Copyright (c) 2026, RoXimn. All rights reserved.
# ******************************************************************************
"""The line-number gutter module.

The gutter is a right-edge strip of line numbers, one per document line,
rendered in Eastern or Western digits. It is off by default; the host opts
in via :meth:`PyRaya.setGutterEnabled`.

The digit conversion reuses :func:`~pyraya.regions.substituteText` from
`regions.py` rather than defining a new digit table.
"""

from enum import IntEnum

from .regions import RegionType, substituteText


# ******************************************************************************
class DigitSet(IntEnum):
    """The digit set the gutter renders line numbers in.

    A closed IntEnum mirroring :class:`~pyraya.regions.RegionType`.
    """

    Western = 0
    Eastern = 1


# ******************************************************************************
def formatLineNumber(number: int, digitSet: DigitSet) -> str:
    """Format a 1-based line number as a digit string.

    Eastern digits are produced by substituting each ASCII digit
    ``0-9`` with its Eastern Arabic-Indic equivalent via
    :func:`~pyraya.regions.substituteText` (the ``RomanUrdu`` table);
    Western digits pass through unchanged (identity).

    Args:
        number: The 1-based line number to format.
        digitSet: The digit set to render in.

    Returns:
        The formatted digit string.
    """
    text = str(number)
    if digitSet is DigitSet.Eastern:
        return substituteText(text, RegionType.RomanUrdu)
    return text
```

Add the `GutterArea` class:

```python
class GutterArea(QWidget):
    """The line-number strip: one number per visible document line.

    A child of :class:`~pyraya.PyRaya`, **sibling of the viewport**,
    placed at the right edge of ``contentsRect``. It paints the line
    numbers in Eastern or Western digits, coloured by the theme stop,
    with a 1 px border on the text-facing (left) edge.

    The gutter is read-only over the document: painting never edits,
    never re-highlights, never bumps the revision, never touches the
    undo stack.
    """

    def __init__(self, parent: QWidget) -> None:
        """Initialize the gutter strip.

        Args:
            parent: The parent widget (the :class:`PyRaya` instance).
        """
        super().__init__(parent)
        self._digitSet: DigitSet = DigitSet.Eastern
        self._gutterFont = parent.font()

    def setDigitSet(self, digitSet: DigitSet) -> None:
        """Set the digit set for line numbers.

        Args:
            digitSet: The digit set to render in.
        """
        self._digitSet = digitSet

    def setGutterFont(self, font: QFont) -> None:
        """Set the gutter font (independent of the document font).

        Args:
            font: The font to use for line numbers.
        """
        self._gutterFont = font

    def paintEvent(self, event: QPaintEvent) -> None:
        """Paint the line numbers for visible blocks only.

        Walks visible blocks only (bounded to the dirty rect —
        load-bearing for the 200 k latency budget), draws each 1-based
        number with the converted digit string, physical
        ``AlignVCenter | AlignLeft`` (painter alignment flags are
        physical, so the widget's RTL layout direction does not flip
        them), then a 1 px splitter on the text-facing (left) edge.
        Colours are resolved **per paint** from
        ``resolveTheme(self.palette())``.
        """
        from typing import cast

        parent = self.parent()
        if parent is None:
            return
        # parent is PyRaya (a QPlainTextEdit)
        editor = cast("PyRaya", parent)
        painter = QPainter(self)
        painter.setRenderHint(QPainter.RenderHint.Antialiasing)

        tokens = resolveTheme(self.palette())
        painter.fillRect(self.rect(), tokens.gutterBackground)

        # 1 px border on the text-facing (left) edge
        pen = QPen(tokens.gutterBorder)
        painter.setPen(pen)
        painter.drawLine(0, self.rect().top(), 0, self.rect().bottom())

        # Walk visible blocks only
        first = editor.firstVisibleBlock()
        if not first.isValid():
            return
        last = editor.firstVisibleBlock(editor.document().lastBlock())

        # The dirty rect bounds the paint
        dirty = event.rect()

        for block in self._iterVisibleBlocks(editor, first, last, dirty):
            number = block.blockNumber() + 1  # 1-based
            text = formatLineNumber(number, self._digitSet)
            # Gutter-local y: block top edge relative to the gutter's origin
            top = int(
                editor.blockBoundingGeometry(block)
                .translated(editor.contentOffset())
                .top()
            )
            # Clip to dirty rect
            if top > dirty.bottom() or top + block.height() < dirty.top():
                continue
            # Paint the number, physically left-aligned, vertically centred
            painter.setPen(tokens.gutterText)
            fontMetrics = QFontMetrics(self._gutterFont)
            textHeight = fontMetrics.height()
            painter.setFont(self._gutterFont)
            painter.drawText(
                1,  # left padding (after the 1 px border)
                top + (block.height() - textHeight) // 2,
                text,
            )
        painter.end()

    def _iterVisibleBlocks(
        self,
        editor: "PyRaya",
        first: QTextBlock,
        last: QTextBlock,
        dirty: QRect,
    ) -> list[QTextBlock]:
        """Yield visible blocks within the dirty rect, bounded.

        Args:
            editor: The parent PyRaya widget (a QPlainTextEdit).
            first: The first visible block.
            last: The last visible block.
            dirty: The dirty rect to bound the walk.

        Returns:
            The list of blocks to paint.
        """
        blocks: list[QTextBlock] = []
        block = first
        # Walk forward from the first visible block
        while block.isValid():
            top = int(
                editor.blockBoundingGeometry(block)
                .translated(editor.contentOffset())
                .top()
            )
            if top > dirty.bottom():
                break
            if top + block.height() >= dirty.top():
                blocks.append(block)
            if block == last:
                break
            block = block.next()
        return blocks
```

   ```python
       """Enable or disable the line-number gutter.

       When enabled, reserves the right margin via
       ``setViewportMargins(0, 0, width, 0)`` and creates the
       :class:`GutterArea` child widget (sibling of the viewport).
   ```

   ```python
   def _findGutter(self) -> GutterArea | None:
       """Find the GutterArea child widget, or None if not created."""
       for child in self.findChildren(QWidget):
           if isinstance(child, GutterArea):
               return child
       return None

   def _ensureGutter(self) -> None:
       """Create the GutterArea if it does not exist and show it."""
       gutter = self._findGutter()
       if gutter is None:
           gutter = GutterArea(self)
           gutter.setDigitSet(self._gutterFormat)
           gutter.setGutterFont(self._gutterFont)
       gutter.show()

   def _removeGutter(self) -> None:
       """Hide the GutterArea and remove the right margin."""
       gutter = self._findGutter()
       if gutter is not None:
           gutter.hide()
       self.setViewportMargins(0, 0, 0, 0)

   def _updateGutterWidth(self) -> None:
       """Recompute the gutter width from the largest visible line number.

       The width formula: ``max(3, digits of largest visible line number)
       x digit advance + padding split both sides``. The advance is
       measured with the gutter font's metrics. The result is applied
       only when it differs from the current width (no-op guard).

       The largest visible line number is found via
       ``cursorForPosition(QPoint(vp.width() // 2, vp.height() - 1))`` +
       ``findBlock(...).blockNumber() + 1`` (1-based).
       """
       vp = self.viewport()
       if vp is None or vp.height() == 0:
           return
       cursor = self.cursorForPosition(QPoint(vp.width() // 2, vp.height() - 1))
       block = self.document().findBlock(cursor.position())
       if not block.isValid():
           return
       largest = block.blockNumber() + 1  # 1-based
       digits = max(3, len(str(largest)))

       # Measure digit advance with the gutter font's metrics
       fontMetrics = QFontMetrics(self._gutterFont)
       advance = fontMetrics.horizontalAdvance(
           "۹" if self._gutterFormat is DigitSet.Eastern else "9"
       )
       em = fontMetrics.horizontalAdvance("M")
       padding = int(em * 1.5)
       width = digits * advance + padding

       if width == self._gutterWidth:
           return  # no-op guard

       self._gutterWidth = width
       self.setViewportMargins(0, 0, width, 0)
       self._repositionGutter()

   def _repositionGutter(self) -> None:
       """Re-position the GutterArea at the right edge of contentsRect."""
       gutter = self._findGutter()
       if gutter is None:
           return
       cr = self.contentsRect()
       gutter.setGeometry(
           cr.right() - self._gutterWidth,
           cr.top(),
           self._gutterWidth,
           cr.height(),
       )
       gutter.raise_()
   ```
